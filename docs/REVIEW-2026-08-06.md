# causal-hypothesis-engine — full review and hardening

**Date:** 2026-08-06 · **Baseline commit:** `79eba01` · **Work commit:** `befb599`
**Branch:** `worktree-causal-engine-hardening`

Four independent reviews (engineering/architecture, code review, product,
analyst/methodology) plus direct verification by running the code. Every
finding below was confirmed by execution, not by reading alone.

---

## 1. Where the repo was

A Python 3.12 package, ~9.6k lines (4.6k source / 5.0k tests), 12 CLI
commands, SQLite persistence, two data adapters, three "agents", a diff
engine, four export formats and a 3D viewer. Genuinely well-structured in
places: the pydantic domain model is clean, migrations existed from day one,
`comparison.py` is pure and well-tested, and the error convention
(Problem/Cause/Fix) is applied with unusual discipline.

**262 tests passed. They passed while all of the following was true.**

### The three findings that mattered most

**1. The backtest score was provably independent of the DAG.**
`grep` for `.edges` across `adapters/` and `backtest_agent.py` returns
nothing. `build_proxy_features` iterates `version.nodes` and collects columns.
Reverse every arrow, delete every edge, split the graph into disconnected
components — the score, the lift and the per-node contributions are
identical. The product's central claim ("scores the DAG's proxy features")
described something the computation did not do.

**2. The engine reported a metric it was not computing.**
`scikit-learn` was imported but never declared in `pyproject.toml`. On a
default install the import failed, `except ImportError: pass` swallowed it,
and scoring fell through to mean absolute Pearson correlation rescaled into
`[0.5, 1.0]` — while the results panel printed *"Lift is the increase in AUC
(area under the ROC curve)"*. Measured on identical data: **AUC 0.6852 vs
fallback 0.6526**. Close enough to look plausible, and nothing recorded which
had run.

**3. Nothing enforced acyclicity.** The only mentions of "cycle" in the
codebase were inside LLM system prompts. A three-node cycle A→B→C→A
constructed, validated, persisted, diffed and exported without complaint.

## 2. What was fixed

Commit `befb599`. Tests **262 → 290**, all passing.

### Scoring is now honest
- `scikit-learn` and `scipy` declared; the silent fallback is gone.
- `claim_amount` removed from baseline features. On the demo data the honest
  lift is **+0.2100**, not the +0.0170 the leakage was masking.
- Scaling moved inside a `Pipeline` so it re-fits per fold.
- Fixed 5-fold `StratifiedKFold` with an explicit minimum-minority
  precondition that *refuses to score* rather than silently reshaping the CV.
- Paired percentile-bootstrap intervals on lift and on every node
  contribution, with a three-way verdict. A node whose interval spans zero now
  reads **inconclusive**, not "yes".
- `BacktestResult` records metric name, n, class balance, CV scheme and seed.

### The graph is now a graph
- New `graph.py`: iterative-DFS cycle detection (no recursion limit),
  dangling-edge and duplicate-label checks, **d-separation**, and enumeration
  of the DAG's **testable implications**.
- `DAGVersion` rejects cycles at construction — so they cannot be built,
  saved, or loaded.
- `Validated` nodes are included in scoring; outcome-derived columns are
  refused as proxies; missing columns are excluded with an explanatory warning
  rather than zero-filled.

### The loop closes
Three new commands:
- **`causal-engine bind`** — binds a node to its data column(s). This is what
  makes a user-built DAG backtestable; previously only `demo` could do it.
- **`causal-engine explore`** — profiling, missingness, complete-case count,
  correlation structure, collinearity warnings.
- **`causal-engine check`** — tests the conditional independencies the DAG
  implies against real data via partial correlation. **This is the only
  evaluation in the engine whose result depends on edge direction.** A
  rejection is real evidence against the structure.

The BACKTEST prompt was rewritten to state explicitly that confounders are
retained regardless of lift, that high contribution is a reason to suspect a
collider, and that `Validated` cannot be earned by an AUC delta.

### Also fixed
Empty-message history corruption, SQLite connection leak (plus a `health()`
method so `doctor` stops reaching into the connection factory), XSS via
`textContent` and `</` escaping, script-ordering race and pinned CDN versions,
SSRF guard and 64MB response cap, `.env` key allowlist, atomic checkpoint
writes (`mkstemp` + `os.replace` + directory fsync), the f-string bug,
transform-metadata mismatch, duplicated warning output, and all
`datetime.utcnow()` occurrences.

## 4. Blocking gaps — now closed

The four items that made the engine unusable in practice have been fixed in a
second pass (tests **290 → 305**).

**The financial path scores.** `FinancialDataAdapter` implements
`resolve_outcome`, `build_proxy_features`, `compute_dag_score` and
`score_detail`, and is registered in the backtest registry. `load_data` now
accepts either a YAML manifest or the Parquet that `causal-engine dataset`
produces, so `dataset` → `backtest` is a working sequence. Continuous outcomes
are scored by out-of-fold R², binary by AUC; the metric name travels with the
number.

**A generic adapter exists.** `TabularAdapter` (`--adapter Tabular`) imposes no
schema at all. Declare the outcome with `--outcome`, or bind the Outcome node,
and every measured node contributes its columns. Non-numeric proxies are
one-hot encoded. Verified against a dataset with none of the insurance
columns: the real driver scored *adds signal* (+0.2466, CI +0.1804…+0.3049)
and a pure-noise column *inconclusive* (+0.0025, CI −0.0048…+0.0116).

**`DatasetResult` is persisted.** Schema migration 2 adds a `dataset_results`
table keyed by `version_id`, plus the two missing indexes on
`dag_versions(network_id)` and `sessions(network_id)`. `causal-engine dataset`
writes the record and prints the link.

**`resume` respects session mode.** A Modification session now resolves its
source version from the checkpoint's `parent_version_id` and rebuilds a
`ModificationAgent`, preserving lineage and rationale. If the source cannot be
resolved it refuses with an actionable message rather than silently saving an
orphan version.

`Clinical` was removed from `causal-engine new --adapter`: it has no
implementation, and offering it created networks that could never be scored.

## 5. What is still outstanding

Ranked. None of this is started.

### Methodology
1. No point-in-time correctness: FRED returns latest-vintage data, no
   publication lag, `end_date` defaults to today.
2. Resample bins overshoot the declared `end_date` (weekly `W` is
   right-labelled); partial boundary bins are not flagged.
3. Auto-diff on ADF non-rejection over-differences — failing to reject is not
   evidence for the null. Should pair with KPSS.
4. No holdout and no search-path accounting across `modify`→`backtest`
   iterations. For ~20 scored variants, expected spurious best-of-search lift
   is roughly +0.012 to +0.042 AUC from selection alone.
5. No adjustment sets, no effect estimation, no refutation. `check` makes the
   structure falsifiable; it does not yet estimate anything. Handing the graph
   to DoWhy is the cheap route.
6. No lag support — the financial feature matrix is strictly contemporaneous,
   so temporal precedence is unused.
7. No exposure base or claim development in the insurance schema —
   frequency/severity separation is not possible, and conditioning on
   claim-occurrence is itself a collider.

### Engineering
8. No CI, no lint config, no coverage gate.
9. Tests construct a live `Anthropic()` client — inject it so the LLM path
   becomes testable. This is the single highest-leverage test change.
10. `cli.py` (now ~1,200 lines), `modification_agent.py`, `dag_agent.py` all
    exceed the project's own 500-line rule; the two agents are ~40% duplicated.
11. Storage paths still hardcoded to `Path.home()`; model ID still hardcoded
    in two files.
12. Unbounded tool-use loop in `dag_agent.py`; checkpoint counter can skip.
13. Cycle pre-checks are not wired into the agents' `add_edge` paths — a
    cyclic proposal is caught at save time rather than rejected mid-turn with
    a message the model can correct from.
14. `delete_network` still does not cascade and will raise on a non-empty
    network.

## 6. Honest position

The engine is now internally consistent and complete as a workflow: it reports
the metric it computes, refuses to store a non-DAG, works with arbitrary
tabular data, scores both the insurance and financial paths, remembers which
data belongs to which hypothesis, and can be driven end-to-end by someone who
did not write it. `check` gives it a genuinely causal capability it did not
have.

It is still a **hypothesis registry with a predictive screen attached**, not a
causal inference engine. The defensible niche is the governance layer around
causal DAGs — versioned hypotheses, provenance, the measurability lifecycle,
variable-to-data binding — with inference delegated to DoWhy or Tetrad rather
than reimplemented. Item 9 above is the shortest path to making the word
"causal" fully honest.
